    何を学ばないかを決める

    注意は希少な資源であり、増やすことはできない。 読み、観て、聴くことのすべてはできない。選ばざるをえない。

    FOMO は事実だが、恐れる必要はない

    すべてを能動的に消費していなければ何か重要なものを取りこぼす──この取り残される恐れ（FOMO）は実在する。

    だが泡を割ってしまえば、すべてを読むことも観ることも聴くこともできない。この段落を読むあいだに、およそ一週間分の動画が新たに投稿されている。

    慰めになる事実がある。技術に本当に大きなことが起きれば、耳に入る。 最初の発表は見逃すかもしれないが、それでよい。

    人脈も使える。友人や同僚の関心は自分と違う。学習を複数の人に分散させることに何も悪いところはない。

    理由なしに学ばない

    履歴書駆動開発をしない。 何か新しいものを学ぶには「なぜ」が要る。必要になるまで学ぶのを待ってよい。過大評価されていると直観が告げるなら、一拍置いてから投資しても構わない。

    Nate はデータベースをもっと知ろうと、ある日その主題の本を開いた。20分後、彼は本を置いて階上へ行き、靴下の引き出しを整理した。比喩ではない。靴下の引き出しのほうが優先度が高いと判断したのだ。この主題に情熱を持っていないという紛れもない合図だった。

    学習時間を予定に入れるのは容易だが、何を学ぶべきかという問いは残る。興奮しない主題のために日々の時間を作るのは難しい。本を置いても、動画を半分で止めてもよい。完走に追加点はない。

    振り子は揺れ、古いものは戻ってくる

    ソフトウェアでは型がしばしば繰り返し、物事は両極の間を振り子のように揺れる。 古いものが埃を払われ、改名され、誰もやったことがないかのように再登場するのは珍しくない。

    次の記述を読んでほしい。「異なるプログラミング言語で書かれ、さまざまな計算機で動くソフトウェア部品が、互いに通信し協働できるようにする手法」。マイクロサービスを思い浮かべただろうか。当てはまる。 だがこれは1990年代に流行した CORBA の定義である。

    ただし直観は割り引いたほうがいい。Paul Graham は2001年、自らの基準を Java に当てて「この言語はあまり成功しないだろうという予感がする」と書いた。20年以上を経た今、Java は史上最も成功した言語の一つである。彼ほどの人がこれほど外しうるなら、自分の直観も割り引くのが賢明だ。

    情熱は採用の理由にならない

    すべての新しいものについていけないのと同じく、すべてを採用することもできない。 ある道具への情熱は、それがプロジェクトに適することを自動的には意味しない。利点だけでなくすべての帰結を考える。

    そして自分の文脈で試す。検証は、その技術が実際に出会う制約のもとで行う。

    あるチームは、何年も使ってきた UI ライブラリが限界に達し、三つの候補に絞って更地での検証を行った。一つを選び、既存のアプリケーションに少しずつ振りかけていく計画を立てた。六ヶ月後、彼らは悟った──このライブラリは少しずつ足せるものではなく、真に使うには全面的な書き直しが要る。 既存プロジェクトのフォークで検証していれば、ずっと早く気づけた。それでも同じものを選んだかもしれないが、少なくとも目を開いた状態で選べた。

    更地で to-do 一覧が動いたからといって、その技術が自分の環境との接触を生き延びるとは限らない。練習した通りに試合をすることになる。

    自分に猶予を与える

    移り変わる技術についていくことは重要だが、非常に圧倒されうる。先端に立ち続けようとして燃え尽きるのは驚くほど簡単だ。学習は楽しみであるべきで、人生の緊張の元であってはならない。 良い睡眠や心身の健康を犠牲にしてまでやることではない。

    最後の責任ある瞬間まで学習を待つことに、何も悪いところはない。 ソフトウェアの空間は、先月の新しい熱狂の残骸で散らかっている。いつ学び始めてよいかに時効はない。 定着力が証明されたなら、来週でも来年でも拾える。

    効く条件

    • 学ぶべきものが多すぎて麻痺しているとき。「なぜ」がないものを落とす判断ができる
    • 新しい技術の採用を検討するとき。既存プロジェクトのフォークで試す判断が、六ヶ月後の後悔を防ぐ
    • 情報を追うことに疲れたとき。大きなことは耳に入る、という事実が休むことを許す

    効かない条件

    ここから先は本書が書いていない領域で、読み手として当て込んだ限界である。

    • 職務上、幅広い技術動向の把握が求められる立場。選択的であることが職務放棄になりうる
    • 分野そのものが急変している時期。「決着を待つ」判断が、致命的な出遅れになることはある
    • 情熱を基準にしすぎる場合。業務上必要だが退屈な領域は、それでも学ばねばならない
