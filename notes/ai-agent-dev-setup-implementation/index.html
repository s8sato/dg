# delegate-review

1. 引数の指示を独立したサブタスクに分割し、各々を delegate-worker サブエージェントに並列で委任する
   - 独立したサブタスクに分割できないときは委任せず、自分で作業する
   - 委任文に目的・制約・成果物の形式・参照すべきパスを含める
   - 難しい作業では Agent ツールの model 引数で worker のモデルを上書きする
   - レビュー観点は worker に渡さない（検証の独立性を優先）
2. 報告を待つあいだ、指示からレビュー観点を構築する
3. 全報告の受領後、成果物を観点に沿ってレビューし、結果を成果物として報告する

plan モードでは成果物を計画ファイルとし、delegate-worker には計画を報告させ、自身のレビューを反映して計画ファイルに書く

    delegate-worker サブエージェント

    agents/delegate-worker.md

    ---
name: delegate-worker
description: delegate-review スキルから委任された作業を実行する
model: sonnet
effort: medium
---

委任された作業を実行し、成果物を報告する。

報告の形式:

- 結論
- 根拠
- 未確認事項
- 前提にした仮定

事実と推測を区別して書く。

    advisor

    /advisor でモデルを選んで有効にする。設定ファイルはない。
